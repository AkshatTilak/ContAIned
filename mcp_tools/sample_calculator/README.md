# Sample Calculator MCP Server

A sample arithmetic MCP tool server exposing basic math operations (`add`, `subtract`, `multiply`, `divide`, `power`).

## Tools Included
- `add`: Adds two numbers (`a + b`).
- `subtract`: Subtracts `b` from `a` (`a - b`).
- `multiply`: Multiplies two numbers (`a * b`).
- `divide`: Divides `a` by `b` (`a / b`) with divide-by-zero protection.
- `power`: Calculates `base ^ exponent`.

## Running the Server
```bash
python server.py --port 8092
```
